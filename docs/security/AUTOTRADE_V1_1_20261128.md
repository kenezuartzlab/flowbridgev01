## 2. Persistent worker
- Managed schedule `autotrade-worker` (job 334, every minute = 1,440 runs/day) → `/api/public/hooks/autotrade-worker` (managed scheduler secret or AUTOTRADE_WORKER_SECRET).
- Fenced DB lease (`autotrade_acquire_lease/heartbeat/release`, 30 s TTL): a second concurrent call returned `LEASE_HELD`; a crashed holder is replaced after TTL with a higher fencing token, and a stale holder's heartbeat fails (`LEASE_LOST`).
- Polls every 1.5 s for ~45 s per invocation, always jumps to the newest block (coalesced blocks are counted), max 6 orders per block, one order at a time (fits the 6-connection limit).
- Fail-closed: head/hash at a common height must match between rpc.botchain.ai and the Blockscout explorer JSON-RPC (different host and data path, **same ecosystem operator — not operator-independent**). On divergence no orders are processed.
- Measured (preview, manual benchmark run, 8 processed blocks): block-to-decision delay **p50 2,621 ms, p95 3,037 ms**; ~5.6 s per cycle, so ~6–8 of every ~8 one-second blocks were coalesced. 5 of 8 cycles failed closed with RPC_HEAD_DIVERGENCE at a 3-block tolerance; tolerance is now 10 blocks with hash check kept. Scheduled-run samples were not yet recorded at report time.

## 3. Live executor (built, hard-disabled) — src/lib/autotrade/executor.ts
- Closed allowlist: Router V4 only; selectors swapV3MultiSafe / swapNativeToTokenV3MultiSafe / swapTokenToNativeV3MultiSafe from the generated ABI, each verified present in deployed bytecode.
- Deployment identity: chain 677, runtime keccak `0x13f0ab26…9ad0`, not paused, venue #0 BDEX V3 active, WBOT, routerFeeBps==1.
- Fee once: `planAmounts` picks the largest swap with swap+floor(swap·bps/1e4) ≤ budget; maxProtocolFee = that exact fee; minOut floors use the total pulled.
- Exact approval = pulled, revoke on any failure; gas cap separate; nonce reservation; outbox RESERVED→SIGNED→BROADCAST→MINED→FINAL(6 conf) with REVERTED/REPLACED/DROPPED terminal; reorg returns to BROADCAST and only the same signed bytes are rebroadcast.
- Output measured from Transfer logs to the trader / native balance delta + gas.
- `assertExecutionAllowed`: LIVE_DISABLED → emergency pause → signer → RPC consensus → deployment identity.

## 4. Trading account
No account created. Preferred: non-exportable managed signer bound to one dedicated EOA (never owner/treasury/rewards/payout), balance ≤ 5 USDT.
Fallback hot EOA in a server secret = full key-theft risk for its balance. AutoTrade accounts listed in `autotrade_trading_accounts` are rejected by Router V4 reward ingestion.
